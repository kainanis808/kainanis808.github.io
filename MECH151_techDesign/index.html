MECH 151: Technical Design - Prototyping

Welcome to the MECH 151: Technical Design - Prototyping course page! This course is designed to provide students with a comprehensive understanding of the technical design process, from concept development through functional prototyping. Throughout the course, we will explore various topics related to design and prototyping, including design methodology, CAD modeling, rapid prototyping techniques, and iterative testing.

In this course, students will learn about the fundamental principles of technical design and prototyping and how they apply to real-world engineering problems.

Course Description

This course introduces the student to 3D modeling using CAD/CAM mechanical design automation software. Topics included are: sketching, orthographic projection, descriptive geometry, dimensioning, section views, auxiliary views, primary and secondary views, threads, fasteners, and production drawings. Students will build parametric models of parts and assemblies and make drawings of those parts and assemblies. The student will study CAD/CAM software configurations and translate parametric models to produce prototypes using various manufacturing methods. The course will also cover basic machine safety and operation.

A Note on CAD Software

This course is intentionally CAD-program-agnostic. The field of CAD software is far too broad for one course to teach every package in depth, so no single program (SolidWorks, Fusion 360, Onshape, Inventor, or otherwise) is "the" software for this class. Instead, the course focuses on the fundamental operations and tools that virtually every parametric CAD program shares — sketching and constraints, extrude/revolve/sweep/loft, feature trees, mates/assembly constraints, drawing views, and so on — even though the exact menu names for these tools vary from program to program. Once you understand the underlying operation, translating it to whatever software you use in this class, an internship, or a future job is straightforward.
