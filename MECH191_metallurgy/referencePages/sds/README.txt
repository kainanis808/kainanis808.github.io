SDS FOLDER — MECH191 Metallography Lab
=========================================

These are the manufacturer Safety Data Sheets (ES Laboratory, LLC) for the
six etchants used in the lab, linked from etchant_sds.html. Filenames must
match exactly for the links on that page to resolve:

  nital-etch-2-sds.pdf              Nital Etch, 2% to 5%
  marbles-reagent-sds.pdf           Marble's Reagent
  kallings-2-reagent-sds.pdf        Kalling's 2 Reagent
  kellers-reagent-sds.pdf           Keller's Reagent
  krolls-reagent-sds.pdf            Kroll's Reagent
  acidic-ferric-chloride-sds.pdf    Acidic Ferric Chloride (ASTM 34)

If the supplier issues a revised SDS for any of these, replace the file
using the SAME filename above and etchant_sds.html will pick it up
automatically — no other changes needed.

If you ever switch etchant suppliers or add a new etchant, name the new
PDF descriptively (e.g. new-etchant-sds.pdf) and add a matching entry +
link on etchant_sds.html.
